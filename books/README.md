# Posts and Books

- Add essays and miscellany under `posts/`. Pair Markdown sources with a small `.html` reading page and list them in `posts/index.html`.
- Add books under `books/`. Put downloadable files in `books/files/` and add a title, description, and link in `books/index.html`.
- Published paths: `https://huiquanr.github.io/posts/` and `https://huiquanr.github.io/books/`.
